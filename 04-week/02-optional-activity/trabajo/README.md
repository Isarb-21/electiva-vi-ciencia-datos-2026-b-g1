## Problem & data
The industrial process analyzed in this project focuses on industrial equipment maintenance. Unexpected equipment failures interrupt production and increase operational costs. The required dataset includes operational metrics (temperature, vibration, pressure, electrical current, operating hours) and historical records (failure history and maintenance logs) gathered from IoT sensors, monitoring systems, and technical reports. Predictive analytics serves as the primary approach by leveraging historical and real-time data to identify patterns and forecast failures, matching real-world industrial implementations where sensor monitoring supports timely maintenance decisions.
